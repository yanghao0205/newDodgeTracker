# DodgeTracker 躲避列表工具

## 安装指南
1. 下载并安装 **Pengu Loader**（要求版本 >= 1.1.6）
2. 在[发布页面](https://github.com/yanghao0205/newDodgeTracker/releases/tag/DodgeTracker)下载 `newDodgeTracker.zip` 文件
3. 将文件解压后放入客户端的 `plugins` 插件文件夹中

## 如何添加玩家到躲避列表？
### 方法一：手动添加
1. 打开英雄联盟客户端设置
2. 找到「躲避追踪器」并点击「躲避列表」
3. 在输入框按格式输入：`玩家名称#标签`（例如：`疾风剑豪#456894`）
4. 点击「添加玩家」完成操作

### 方法二：快捷操作
在以下界面右键点击玩家名称：
- 对局结算界面
- 历史战绩页面
- 组队房间列表  
选择「死亡笔记」选项即可

## 功能特性
- 支持玩家名称的**标签（Tag）**和**备注**功能
- 自动适配客户端语言（中文客户端显示中文，其他语言客户端显示英文）

## 版本更新 (2025年5月)
### 新增功能：数据导入导出
我们在最新版本中添加了数据导入导出功能，让您可以轻松备份和迁移躲避列表数据。

#### 主要功能
- **导出功能**：将躲避列表数据导出为文本文件，方便备份和迁移
- **导入功能**：支持两种导入方式
  - 粘贴导入：直接粘贴JSON格式的躲避列表数据
  - 文件导入：选择之前导出的躲避列表文件

#### 如何使用
1. **导出躲避列表**
   - 打开躲避列表界面
   - 点击顶部的「导出躲避列表」按钮
   - 系统会自动下载包含躲避列表数据的文本文件
   - 文件名格式为：`dodge_list_年-月-日.txt`

2. **导入躲避列表**
   - 打开躲避列表界面
   - 点击顶部的「导入躲避列表」按钮
   - 选择导入方式：
     - 「粘贴导入」：粘贴之前导出的JSON数据
     - 「文件导入」：选择之前导出的躲避列表文件
   - 点击「导入数据」按钮完成导入

# DodgeTracker

## Installation Guide
1. Download and install **Pengu Loader** (requires version >= 1.1.6)
2. Download the `newDodgeTracker.zip` file from the [Releases page](https://github.com/yanghao0205/newDodgeTracker/releases/tag/DodgeTracker)
3. Extract the ZIP file into the client's `plugins` folder

## How to Add Players to Dodge List?
### Method 1: Manual Addition
1. Open League of Legends client settings
2. Navigate to "Dodge Tracker" and click "Dodge List"
3. Input in the format: `PlayerName#Tag` (e.g., `Yasuo#456894`)
4. Click "Add Player" to complete

### Method 2: Quick Action
Right-click player names in the following interfaces:
- Post-game lobby
- Match history page
- Party member list  
Select "Add to Dodge List" option

## Features
- Supports **player tags** and **notes**
- Automatic language adaptation based on client settings (Chinese for CN client, English for others)

## Version Update (May 2025)
### New Feature: Data Import/Export
In our latest version, we've added data import/export functionality, allowing you to easily backup and migrate your dodge list data.

#### Key Features
- **Export Function**: Export dodge list data to a text file for backup and migration
- **Import Function**: Supports two import methods
  - Paste Import: Directly paste JSON-formatted dodge list data
  - File Import: Select a previously exported dodge list file

#### How to Use
1. **Exporting Dodge List**
   - Open the dodge list interface
   - Click the "Export Dodge List" button at the top
   - The system will automatically download a text file containing your dodge list data
   - File name format: `dodge_list_YYYY-MM-DD.txt`

2. **Importing Dodge List**
   - Open the dodge list interface
   - Click the "Import Dodge List" button at the top
   - Choose an import method:
     - "Paste Import": Paste previously exported JSON data
     - "File Import": Select a previously exported dodge list file
   - Click the "Import Data" button to complete the import
